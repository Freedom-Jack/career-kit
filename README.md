# Career Toolkit

> Career materials, as code.

A version-controlled home for my professional materials and the workflows that keep them up to date. What started as an automated résumé build can grow into a toolkit for creating, maintaining, and publishing career content.

## How it works

**Edit source → Push changes → GitHub Actions → Generate PDF → Portfolio**

My résumé is maintained in this repository. When I push updates, GitHub Actions builds a fresh PDF that can be accessed through my personal website.

## What's here today

- **Résumé source** — One place to maintain and version my résumé.
- **Automated PDF builds** — GitHub Actions renders an updated PDF on push.
- **Portfolio integration** — A public home for the résumé linked from my website.

## Where it could go

- **Tailored applications** — Role-specific résumés and reusable cover-letter templates.
- **Structured career data** — A shared source for résumés, bios, and portfolio content.
- **Publishing tools** — More document formats, versioned releases, and automated checks.
- **Career resources** — Selected interview-preparation materials and project highlights.
